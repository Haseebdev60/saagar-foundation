# Contact section update

The contact area has been redesigned to follow the reference layout while preserving Saagar Foundation's existing navy, gold, ivory, and forest-green brand palette.

## Changes
- Contact information and a WhatsApp call-to-action on the left.
- White rounded contact form card on the right, with name, email, and message fields.
- Responsive single-column layout on mobile and two-column layout on larger screens.
- Form validation and a clear prototype notice; messages are not sent or stored because no backend is configured.
- Existing phone and email contact details are retained.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
